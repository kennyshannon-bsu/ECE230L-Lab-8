## Lab Questions

### In plain English describe the function and use of a multiplexer.
It combines many inputs into a single output, used to act as a data selector.
### In plain English describe the function and use of a demultiplexer.
It takes a single input and routes it to one of many outputs, used to act as a data distributer.
